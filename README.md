# Financial Sales Analysis Dashboard

## Project Overview
An interactive sales analysis dashboard built using Microsoft Excel to evaluate sales performance, profitability, product contribution, and country-wise business results.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers
- Excel formulas and KPI analysis

## Key Metrics
- Total Sales: $118.73M
- Total Profit: $16.89M
- Profit Margin: 14.23%
- Total Units Sold: 1,125,806

## Key Insights
- The United States recorded the highest sales at approximately $25.03M.
- France generated the highest country-level profit at approximately $3.78M.
- Paseo was the leading product by sales, generating approximately $33.01M.
- Paseo also generated the highest product-level profit at approximately $4.80M.

## Features
- Interactive Country and Product slicers
- Monthly sales and profit trend
- Country-wise sales and profit comparison
- Product-wise sales, profit, and units sold analysis

## Data Source
Microsoft Financial Sample dataset.

## Disclaimer
This is a portfolio learning project. Findings are based on the supplied sample dataset.
